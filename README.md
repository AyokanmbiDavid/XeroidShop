🛒 Xeroid Shop
Welcome to Xeroid Shop, a sleek and responsive e-commerce interface built with core web technologies. This project focuses on a smooth user experience for browsing products, managing a wishlist, and handling a shopping cart.
🚀 Features
Dynamic Product Display: Clean UI for browsing gaming gear and tech.
Shopping Cart: Add, remove, and update quantities of items in real-time.
Wishlist: Save your favorite items for later.
Responsive Design: Fully optimized for both desktop and mobile gaming setups.
🛠️ Tech Stack
HTML5: Semantic structure for better SEO and accessibility.
CSS3: Custom styling with Flexbox/Grid for a modern look.
JavaScript (ES6+): Logic for cart calculations, wishlist toggling, and DOM manipulation.
